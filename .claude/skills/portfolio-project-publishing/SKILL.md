# Portfolio project publishing

Use this workflow when adding or updating a portfolio item.

1. Inspect the existing portfolio model, schema, routes, admin workflow, and image conventions.
2. Confirm the project is approved for public display. Do not expose confidential client information.
3. Collect:
   - Project name and slug.
   - Short summary and detailed description.
   - Category and services delivered.
   - Technology tags.
   - Thumbnail and gallery assets.
   - Live demo URL, if approved.
   - Client attribution, only if approved.
   - Completion date and publication status.
4. Validate URLs and image formats. Optimize images and provide useful alt text.
5. Create a case study structure: challenge, approach, solution, and outcome. Do not invent metrics.
6. Ensure the detail page has metadata, Open Graph image, canonical URL, and sensible internal links.
7. Verify responsive gallery behavior, empty states, and external-link safety.
8. Run relevant checks and summarize the published content and any missing information.

Do not invent a sandbox path, live URL, client identity, testimonial, or outcome.
