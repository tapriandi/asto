# SEO page audit

1. Inspect route implementation and rendered content.
2. Check unique title and description, canonical URL, indexability, robots behavior, Open Graph/Twitter metadata, and heading hierarchy.
3. Check image alt text, dimensions, loading behavior, and social preview image.
4. Check internal links, breadcrumbs where useful, sitemap inclusion, and broken links.
5. Add structured data only when accurate and supported by visible page content.
6. Evaluate search intent, clarity, originality, and CTA relevance.
7. Report findings by priority and propose concrete fixes.
8. Implement only after the user asks for implementation; otherwise provide an audit report.

Never invent reviews, ratings, business addresses, prices, or claims.
